# TrendTide — channel setup kit

- **Display name:** TrendTide  ·  **Handle:** `@TrendTide` (fallbacks: `@TrendTideHQ`, `@TrendTideShorts`, `@GetTrendTide`)
- **Tagline:** The story behind what's trending.
- **Why this name:** two everyday words, alliteration (easy to remember/say), "trend" = instant topic signal, no
  numbers or creative spelling (people type exactly what they hear), and it fits Shorts, long-form, TikTok and IG.
- **Voice:** quick, curious, fact-checked, a clear opinion at the end. Never "breaking" clickbait.

## About (paste into YouTube → Customization → Basic info)
> What's trending — and why? TrendTide breaks down the biggest moments in gaming, AI, tech, entertainment and
> internet culture in fast, original Shorts and weekly deep dives. Fact-checked context, our own take, sources in
> every description. Subscribe for the story behind the trend.

**Channel keywords:** trending, viral, explained, gaming news, GTA 6, AI tools, tech news, internet culture, shorts

## Brand design brief
Round icon: a rising trend line that turns into a wave crest. Palette: midnight `#111827`, electric cyan `#22D3EE`,
coral `#FB7185`, white; caption highlight yellow `#EED322`. One bold sans (Inter / Montserrat, both OFL).
Icon readable at 98 px; banner 2560×1440 with text inside the 1546×423 safe area. No game/brand logos.

## Repeatable formats (variety protects against "inauthentic" flags)
1. **Why it blew up** — context, timeline, what's next.
2. **Myth vs Confirmed** — GTA 6 & leaks: official sources vs speculation.
3. **3 details you missed** — your own screenshots/recordings + commentary.
4. **AI tool reality check** — your own screen recording test, honest verdict.
5. **Clip + take** (Lane B) — permissioned moment + your 5-second setup + your verdict.

## Manual creation checklist (you)
- [ ] youtube.com → profile → *Create a channel* → choose **Brand Account** name "TrendTide".
- [ ] Claim handle; verify phone (Studio → Settings → Channel → Feature eligibility).
- [ ] Enable 2-Step Verification on the Google account.
- [ ] Upload icon/banner, About text, links, playlists; set country (Canada), language, audience "not made for kids".
- [ ] Google Cloud: create project → enable YouTube Data API v3 → API key (restrict to YouTube Data API) →
      OAuth consent screen (External, add yourself as test user) → OAuth client *Desktop app* → save JSON as
      `.secrets\client_secret.json`.
- [ ] Submit the **YouTube API Services audit / quota extension form** (needed for public API uploads).
- [ ] TikTok & Instagram: claim the same handle; Instagram → switch to Professional (Creator/Business).
